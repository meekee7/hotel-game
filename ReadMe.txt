Español:

Todos los datos del juego están contenidos en el ejecutable excepto la configuración de dinero por jugador y los ficheros de recursos para otros idiomas.
Por eso hay un fichero XML que debe estar junto al ejecutable.

La interfaz del juego es bastante explicativa e incluye las reglas originales del juego.

El servidor admite un parámetro para indicar el puerto en el que escuchar: server.exe num_puerto

El servidor puede conectarse con una base de datos MySQL para salvar y cargar partidas: utilizar el fichero hotel_db.sql para crear la base de datos, y configurar DBdata.txt para usarla.

No dudéis en conctar con ifilgud@gmail.com si tenéis problemas.

English:

All game data is inside game executable except money per player configuration and resource files needed for other languages.
Thats the reason of a XML file which must be next to game executable.

Game interface is pretty self-explaining and it includes spanish game rules.

If you own the english board game, scan it and mail me!

Server allows you yo specify a listening port number: server.exe port_number

Server can connect to a MySQL database to save and load games: use file hotel_db.sql in order to create the database and configure DBdata.txt to connect to it.

Don't hesistate to contact ifilgud@gmail.com if you have problems.
